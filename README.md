Студентка 2 курса направления **«Прикладная информатика»** (Информатика и вычислительная техника). 

Мой основной фокус — **системное программирование на C++**, **вычислительные алгоритмы и структуры данных**, **разработка приложений на C# / .NET**, а также интеграция программной разработки с инфраструктурными практиками (**DevOps**).

---

### 💻 Стек технологий и компетенции

- **Языки программирования:** `C++ (C++17/20)`, `C# (.NET / Windows Forms)`, `SQL`, `Python (базовый)`
- **Computer Science & Алгоритмы:** Структуры данных, динамическое программирование, жадные алгоритмы, дискретно-событийное моделирование, принципы ООП и управление памятью (RAII)
- **Инструменты и среда:** `Git`, `GitHub`, `Visual Studio`, `Linux / Bash (базовый)`, `Figma`
